Pi Setup — Copy & Paste into Terminal

Click the green box to select, then Ctrl+C to copy. Paste into your Pi terminal with Ctrl+Shift+V.

mkdir -p ~/.ssh && curl -s https://raw.githubusercontent.com/cfritzlen/homestead-inventory/main/pi-ssh-key.txt >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys && echo "done"

It should print "done" when finished.
