Rentals: copy data into Homestead

One-time tool. Copies leases, properties, expenses, payments, rate schedules and receipt files from the old Rental-Manager database into this one. Nothing is deleted from the old database. Safe to run more than once (rows are matched by id).

Step 1: Check both databases

Confirms the new tables exist (from supabase/migrations/012_rentals.sql) and shows what will be copied.

Step 2: Copy everything

Copies rows table by table, then copies each receipt file into the new rental-receipts bucket and updates the links.
